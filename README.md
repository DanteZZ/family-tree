# Родословное древо

Сайт собирается из одного файла с данными — `src/data/family.json` — в один HTML-файл `dist/index.html`, который можно открыть двойным щелчком или отправить родственникам.

## Как обновить

```bash
npm install      # один раз
npm run build    # после каждой правки family.json
```

Посмотреть во время правок: `npm run dev`.

## Как добавить человека

В массив `people` добавляется объект. Связи задаются только у ребёнка — полями `father` и `mother` (это `id` родителей). Дети, братья и сёстры вычисляются сами.

```json
{
  "id": "matvey",                     // уникальный, латиницей
  "given": "Матвей",
  "patronymic": "Кузьмич",            // необязательно
  "surname": "Захаркин",
  "maiden": "Колоткина",              // девичья фамилия, для женщин
  "sex": "m",                         // m или f
  "status": "doc",                    // doc — документ, memory — со слов, hypo — гипотеза, unk — неизвестно
  "line": "zakh",                     // ключ из блока "lines" (для фильтра хронологии)
  "birth": { "date": "~1820", "place": "с. Шувары", "calendar": "julian" },
  "death": { "date": "1879-05-03" },
  "father": "kuzma", "mother": null,
  "spouses": ["daria"],               // если детей в древе нет, а брак есть
  "living": false,
  "notes": ["Любые заметки"],
  "sources": [{ "title": "Ревизская сказка 1858", "url": "https://..." }]
}
```

**Вверх по древу:** добавить родителя как нового человека и прописать его `id` в `father`/`mother` у ребёнка.
**Вниз:** добавить ребёнка и указать у него `father`/`mother`.

Даты: `1913`, `1913-02`, `1913-02-02` или `~1846` (около). `calendar: "julian"` — дата по старому стилю.

## Хронология

Рождения и смерти попадают туда автоматически. Остальные события (свадьбы, переезды, призыв) — в массив `events`:

```json
{ "date": "1947-05-21", "title": "Переезд на Дальний Восток", "text": "...", "line": "zakh", "status": "memory", "url": "https://...", "person": "alexS" }
```

Корень древа (кто в центре при открытии) — `meta.root`.

## Биография и передвижения

- `bio` у человека — массив абзацев подробной биографии (показывается в панели сведений).
- `moves` — список мест по порядку: `{ "date": "1947", "place": "suchan", "note": "переезд", "approx": true }`.
  `place` — ключ из общего словаря `places` в начале JSON: `{ "name": "...", "lat": 43.13, "lon": 133.12, "approx": true }`.
  `approx` у переезда — пунктир на карте (со слов / по косвенным данным); у места — точка условная.
- Вкладки хронологии: «События» (`#timeline`), «Годы жизни» (`#lives`), «Передвижения» (`#moves`).
  В «Годах жизни» недостающие даты оцениваются по родственникам (±27 лет на поколение) и рисуются с размытым краем.
- Карта загружает подложку OpenStreetMap из интернета; без сети точки и линии видны, но без фона.
- `story` — сюжет режима «История» на карте: `{ "from": "1947-05-21", "to": "1947-09", "kind": "move", "people": ["semyon"], "title": "...", "text": "...", "fromPlace": "shuvary", "place": "suchan", "status": "memory" }`.
  `kind`: birth, marriage, move, war, event, death. С `to` событие рисуется диапазоном на дорожке; с `fromPlace` — анимированный переезд.
  Управление: пробел — пауза, ← → — соседние сцены, дорожки и полосу обзора можно тянуть.

## Комментарии «на разбор» (только dev)

При запуске через `npm run dev` в карточке человека есть блок «На разбор»: тип (факт / поправка / зацепка / вопрос), текст и «откуда известно».
Записи сохраняются в `../inbox/comments.json` (папка дела); в шапке — счётчик и список всех записей.
После разбора записи переносятся в реестры дела и `family.json`, а из inbox удаляются. В собранный `dist/index.html` форма не попадает.
